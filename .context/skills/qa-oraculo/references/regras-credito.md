# Regras de negócio de crédito (confirmadas)

Este arquivo é a lista de regras de negócio **confirmadas** que podem servir de fonte de
autoridade para oráculos.

## Como usar

- Só entram regras confirmadas por uma fonte verificável: critério de aceite, documento
  de produto, especificação do parceiro, ou confirmação explícita do dono da regra.
- **Nunca adicione uma regra deduzida do código, de um teste existente ou de suposição.**
- Cada regra tem fonte, dono e data. Regra sem fonte não entra.
- Ao usar uma regra num oráculo, cite o ID dela na tabela de oráculos (`RC-001`).
- Se uma regra parecer desatualizada ou contradizer o código, não escolha um lado:
  reporte no Relatório de QA e pergunte ao dono.
- Para adicionar uma regra durante uma tarefa, peça ao dev a fonte e o dono, e proponha
  a linha. Não grave a regra sem a confirmação dele.
